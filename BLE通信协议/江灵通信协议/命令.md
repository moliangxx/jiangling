# 江灵通信协议 · 命令（CMD）

> 本文件是五份中的第 2 份，只写 **CMD**：App → 车。ACK 结构见 `回复.md`，DAT/LOG 见 `数据.md` / `日志.md`。
> 权威目录：`d:\Esp32Project\index\江灵通信协议\`。
> 只收录**已实现或已明确要做**的命令；未定的放第 6 节「待确认」，不写进长度表。

---

## 0. 适用范围与方向

| 项 | 约定 |
| --- | --- |
| 方向 | **只能 App → 车**。车端收到 CMD 即执行；App 收到 CMD 属方向非法，只回一条错误 ACK |
| 链路 | BLE / WiFi 近程（TCP 8080）/ WiFi 远程（WSS 443）**同一套定义** |
| 帧 | `AA | SEQ | TYPE | PAYLOAD | CRC8`，无 LEN |
| 编码 | TYPE 十六进制，参数十进制 |
| 字节序 | PAYLOAD 内多字节一律**大端**（本版 CMD 全部为 1 B 或无 PAYLOAD，暂不涉及） |

---

## 1. 通用规则

### 1.1 SEQ

| 项 | 约定 |
| --- | --- |
| 范围 | `1~255`；`0` 专用于**免去重**命令 |
| 来源 | App 侧**单一全局计数器**，与链路（BLE/WiFi）无关 |
| 免去重（`SEQ=0`） | `CMD_SESSION_INIT`、`CMD_SELECT_MODE` 等幂等/状态类命令 |
| 去重 | 车端一份 64 条环，收到重复 SEQ 的命令**不重复执行**，但仍回 ACK |
| 重发 | App **不自动重发**；超时只判失败（例外：`SEQ=0` 命令允许人工重发） |

### 1.2 长度与组帧

- 帧长 = `3 + PAYLOAD 长度 + 1`；PAYLOAD 长度只由 `TYPE → 长度表` 决定。
- 收到第 3 字节（TYPE）即可确定整帧长度，可跨 BLE 通知分片 / TCP 读分片重组。
- 未登记 TYPE：整帧丢弃，逐字节重扫 `0xAA`，车端**静默丢弃不回 ACK**。

### 1.3 ACK 期望

- 已实现且已登记的命令：车端回 `ACK_RESULT`（或握手的 `ACK_SESSION_INIT`）。
- 已定义未实现：回 `ACK_RESULT` + `ACK_ST_UNKNOWN(4)`。
- 未登记 TYPE：**无任何 ACK**；App 侧必须超时兜底：局域网 **4 s**、公网 **6 s**。

### 1.4 参数裁剪

- 运动挡位/转弯/音量：App 发送前裁剪到表内范围，越界值丢弃不发（或按上限裁剪）。
- 云台角度：`0~255` 线性映射，App 不裁剪到 180/360，映射在两端一致。
- 车端**始终校验原始参数**，不信任 App 的裁剪。

## 2. CMD 分区与 TYPE 速查

```
TYPE = KIND(bit7-6=11) + 分区(bit5-4) + 类型(bit3-0)
CMD  = 0xC0 | (分区 << 4) | 类型
```

| 分区 | 用途 | 已用 TYPE | 预留 |
| --- | --- | --- | --- |
| 0 | 系统 / 信息 / 模式 | `0xC0`~`0xC3` | `0xC4`~`0xCF` |
| 1 | 音频 | `0xD0`~`0xD3` | `0xD4`~`0xDF` |
| 2 | 动作 / 运动 | `0xE0`~`0xE8` | `0xE9`~`0xEF` |
| 3 | 预留 | 无 | `0xF0`~`0xFF` |

### 2.1 CMD 长度表（与车端硬编码一致）

| TYPE | 名称 | 分区/类型 | PAYLOAD | 帧长 |
| --- | --- | --- | --- | --- |
| `0xC0` | `CMD_SESSION_INIT` | 0/0 | 1 B（协议版本 `20`） | 5 |
| `0xC1` | `CMD_QUERY_SEQ` | 0/1 | 1 B（目标 SEQ） | 5 |
| `0xC2` | `CMD_REQ_INFO` | 0/2 | 0 B | 4 |
| `0xC3` | `CMD_SELECT_MODE` | 0/3 | 1 B（`mode`） | 5 |
| `0xD0` | `CMD_AUDIO_TEST` | 1/0 | 1 B | 5 |
| `0xD1` | `CMD_VOLUME` | 1/1 | 1 B | 5 |
| `0xD2` | `CMD_RECORD` | 1/2 | 1 B | 5 |
| `0xD3` | `CMD_REQ_RECORD` | 1/3 | 0 B | 4 |
| `0xE0` | `CMD_STOP` | 2/0 | 0 B | 4 |
| `0xE1` | `CMD_FORWARD` | 2/1 | 1 B | 5 |
| `0xE2` | `CMD_BACK` | 2/2 | 1 B | 5 |
| `0xE3` | `CMD_LEFT` | 2/3 | 1 B | 5 |
| `0xE4` | `CMD_RIGHT` | 2/4 | 1 B | 5 |
| `0xE5` | `CMD_PITCH` | 2/5 | 1 B | 5 |
| `0xE6` | `CMD_YAW` | 2/6 | 1 B | 5 |
| `0xE7` | `CMD_LEFT_SHIFT` | 2/7 | 1 B | 5 |
| `0xE8` | `CMD_RIGHT_SHIFT` | 2/8 | 1 B | 5 |

> `0xC3` 原为「语音预留」位，本版正式占用为 `CMD_SELECT_MODE`；`0xC4` 及以后仍预留。

## 3. 系统 / 信息 / 模式（分区 0）

### 3.1 `CMD_SESSION_INIT` `0xC0`

| 项 | 内容 |
| --- | --- |
| PAYLOAD | `protocolVersion` u8，当前 `20`（`8 bit（1 B）`） |
| SEQ | **固定 `0`** |
| 时机 | 每次新会话第一帧（BLE 连接后 / WiFi 连上后 / 车端重启后） |
| ACK | `ACK_SESSION_INIT`：`[状态码, resetDone]` |
| 说明 | 版本必须**严格相等**；不等时车端回 `ACK_ST_ERROR` 且 `resetDone=0`，双方停止按本协议解析 DAT |

### 3.2 `CMD_QUERY_SEQ` `0xC1`

| 项 | 内容 |
| --- | --- |
| PAYLOAD | `targetSeq` u8（要查的 SEQ，0~255） |
| SEQ | 普通 `1~255` |
| ACK | `ACK_RESULT`：`[0xC1, 1=有 / 2=无]` |
| 用途 | 手动调试：确认车端去重表里是否已有该 SEQ |

### 3.3 `CMD_REQ_INFO` `0xC2`

| 项 | 内容 |
| --- | --- |
| PAYLOAD | 无 |
| SEQ | 普通 `1~255` |
| ACK | `ACK_RESULT`：`[0xC2, 0=已收到]`，随后补发一轮 `DAT_INFO_*`（`0x83` → `0x84` → `0x85`） |
| 用途 | 握手时信息帧丢失，App 主动补拉 |

### 3.4 `CMD_SELECT_MODE` `0xC3`

| 项 | 内容 |
| --- | --- |
| PAYLOAD | `mode` u8：`0` = 蓝牙、`1` = WiFi 近程、`2` = WiFi 远程 |
| SEQ | **固定 `0`**（免去重，允许安全重发） |
| ACK | **先回 `ACK_RESULT` `[0xC3, 0=已收到]`，再重启** |
| 非法参数 | `mode > 2` → 回 `ACK_RESULT` `[0xC3, 5=错误]`，**不重启** |
| 持久化 | 写入 NVS；重启后按 NVS 初始化（【推导·必要设计】） |
| 默认 | 未写入过时按 `0`（蓝牙） |
| 重启副作用 | SEQ 归零、去重表清空、会话标志重建；App 需按新会话重新握手 |
| ACK 送达 | ACK 发出后建议延迟 ≥ 200 ms 再重启，确保 BLE 通知送达（待实测） |

**重启后的初始化**

| mode | 初始化 |
| --- | --- |
| 0 蓝牙 | 开广播 **15 s**；App 在窗口内连上并下发 `CMD_SESSION_INIT` |
| 1 WiFi 近程 | 连路由器，起 ctrl 8080 / video 81 / audio 8443 |
| 2 WiFi 远程 | 连 relay 443（或 4G 直连），AUTH 后起三条 WSS |

## 4. 音频（分区 1）

| TYPE | 名称 | PAYLOAD | 参数 | ACK 期望 |
| --- | --- | --- | --- | --- |
| `0xD0` | `CMD_AUDIO_TEST` | `mode` u8 | `0` 启动提示音、`1` 1 kHz 测试音、`2` 立即停止 | `0/3/4/5/6` |
| `0xD1` | `CMD_VOLUME` | `volume` u8 | `0~100`，`0`=静音、`100`=满量程 | `1/3` |
| `0xD2` | `CMD_RECORD` | `seconds` u8 | `1~10` 秒，录完设备自动回放 | `0/3/4` |
| `0xD3` | `CMD_REQ_RECORD` | 无 | — | **仅 `4`（未实现）** |

说明：

- `CMD_RECORD` 已实现（固件确认）；参数越界（0 或 >10）应回 `ACK_ST_ERROR`。
- `CMD_REQ_RECORD` 已定义但**当前未实现**，App 与 Debug 页不得把它当作可用命令；由 `DAT_REQ`（请求码 2）触发的场景暂不可用。
- 音量实际响度由功放 GAIN 决定，`100` 不代表某一具体分贝值。

## 5. 动作 / 运动（分区 2）

| TYPE | 名称 | PAYLOAD | 参数范围 | 语义 | ACK 期望 |
| --- | --- | --- | --- | --- | --- |
| `0xE0` | `CMD_STOP` | 无 | — | 急停，最高优先级 | `3` |
| `0xE1` | `CMD_FORWARD` | `level` u8 | `0~100` | 前进，最大线速度百分比 | `0/3/4/5/6` |
| `0xE2` | `CMD_BACK` | `level` u8 | `0~100` | 后退 | `0/3/4/5/6` |
| `0xE3` | `CMD_LEFT` | `turn` u8 | `0~100` | 原地左转，最大角速度百分比 | `0/3/4/5/6` |
| `0xE4` | `CMD_RIGHT` | `turn` u8 | `0~100` | 原地右转 | `0/3/4/5/6` |
| `0xE5` | `CMD_PITCH` | `angle` u8 | `0~255` | 云台俯仰，线性映射 `0°~180°` | `0/3/4/5/6` |
| `0xE6` | `CMD_YAW` | `angle` u8 | `0~255` | 云台水平，线性映射 `0°~360°` | `0/3/4/5/6` |
| `0xE7` | `CMD_LEFT_SHIFT` | `level` u8 | `0~100` | 横向左移 | **仅 `4`（未实现）** |
| `0xE8` | `CMD_RIGHT_SHIFT` | `level` u8 | `0~100` | 横向右移 | **仅 `4`（未实现）** |

规则：

1. 运动命令 PAYLOAD **固定 1 B**，参数 `0` 也必须发 `0x00`，不能省略。
2. 只有 `CMD_STOP` 是 0 字节 PAYLOAD。
3. 车端若 **1 s 内收不到新的运动命令**，自动停止（安全兜底，与链路无关）。
4. 云台/横移属可选硬件：无该硬件时回 `ACK_ST_CANNOT(6)`；横移当前固定回 `UNKNOWN(4)`。

## 7. 完整帧示例

CRC 均为实算值，可直接用于联调。

| 场景 | 帧（含 CRC） | 说明 |
| --- | --- | --- |
| 握手 | `AA 2A C0 14 26` | SEQ=42，`CMD_SESSION_INIT`，版本 20 |
| 切到 WiFi 近程 | `AA 00 C3 01 B6` | SEQ=0，mode=1 |
| 切回蓝牙 | `AA 00 C3 00 B1` | SEQ=0，mode=0 |
| 切到 WiFi 远程 | `AA 00 C3 02 BF` | SEQ=0，mode=2 |
| 前进 100% | `AA 23 E1 64 F0` | SEQ=35，level=100 |
| 急停 | `AA 07 E0 0A` | SEQ=7，无 PAYLOAD |
| 音量 50 | `AA 24 D1 32 BA` | SEQ=36，volume=50 |

> 六行 CRC 均已用 CRC-8/ATM 实算（多项式 `0x07`、初值 `0x00`、覆盖 `AA` 到最后一个 PAYLOAD 字节）。
