## 二、电机驱动（TB6612FNG ×2）

| 项目 | 参数 |
|---|---|
| 型号 | TB6612FNG 双 H 桥模块（红色模块，2 片） |
| 通道 | 每片 2 通道；本车每片只用 **A 通道**驱一侧两轮，两个电机在输出端并联；B 通道输入接 GND、`BO1/BO2` 悬空 |
| 电机电源 VM | 2.5 ~ 13.5 V，接电池组正极 |
| 逻辑电源 VCC | 2.7 ~ 5.5 V；本车接 **3.3 V**（接 5V 时高电平阈值 3.5V > GPIO 3.3V，会识别失败） |
| 连续电流 | 1.2 A / 通道（本车每侧只用 1 路，单侧上限按 1.2 A 计） |
| 峰值电流 | 3.2 A / 通道（< 10 ms） |
| 控制接口 | PWM + 2 路方向 + STBY，3.3V 逻辑直连，无需电平转换 |
| PWM 参数 | 20 kHz / 10 bit（固件 LEDC，高过人耳上限，不啸叫） |
| 待机 | STBY 低电平 = 整片输出高阻；固件上电先把 STBY 拉低 |
| 尺寸 / 安装 | 待实测 |
| 对接注意 | 每侧两只电机在 `AO1/AO2` 上做**负载并联**（同名端并接），不是两路输出并联，也不跨片并联；B 通道输入接地，避免输入悬空；VM 与 GND 之间并 100 µF 电解 + 0.1 µF 瓷片；逻辑地与电机地必须共地；VM 不经降压模块 |

**单路电流核对**：单电机堵转电流 ≈ 1 A（待实测）× 2 只并联 ≈ 2 A，**超过单通道持续电流 1.2 A，低于峰值 3.2 A**。稳态巡航每侧约 0.3 A，余量充足；堵转只允许瞬时存在，靠固件 300 ms 超时自停兜底。若实测出现长时间堵转（爬坡、卡死、轮子被压住），需把占空比限到 60% 以下，或改用持续电流更大的驱动。

## 四、DC 四路降压模块（DC93512）

| 项目 | 参数 |
|---|---|
| 型号 | DC93512 四路电源模块 V2.0 |
| 输入 | 桶形 DC 座或接线端子（二选一）；输入电压范围待实测 |
| 输出 | 三类：3.3V（测速模块）、5V（OUT1 主板、OUT2 音频）、原始电压直通（TB6612 VM 与电压取样） |
| 单路输出电流 | 待实测（铭牌未标） |
| 接口 | 螺丝端子（红 / 绿 / 蓝 / 黄四组） |
| 尺寸 | 待实测 |
| 对接注意 | 先万用表把每路调到目标电压再接负载；功放必须单独一路，不与主板共用；全部 GND 与电池负极共地 |

**电流预算（供电选型依据）**：4 个 TT 电机空转约 0.6 A、转弯约 1.2 A、启动/堵转瞬间可达 4 A；因此动力电从电池直供 TB6612 的 VM，不经过本模块。电压跌落的抑制靠 VM 端的电解电容（见第二节），不靠加大降压模块。

## 五、麦克风功放一体模块（MAX98357A + INMP441）

| 项目 | 参数 |
|---|---|
| 型号 | 功放 + 麦克风一体模块，7Pin + JST 喇叭座 |
| 供电 | 3.3 ~ 5 V；本车从 DC93512 OUT2 取 5V，不从主板 5V 取 |
| 功放芯片 | MAX98357A（I2S 输入 D 类功放，无 GAIN 脚引出，音量靠固件数字增益） |
| 功放输出功率 | 待实测（芯片标称 3.2 W / 4 Ω @ 5 V） |
| 麦克风 | INMP441 数字 MEMS，I2S 输出 |
| 接口 | I2S 全双工：`BCLK` / `LRCLK` / `SDA`（功放 TX）/ `DATA`（麦克风 RX）/ `CLK`（MCLK，本车悬空） |
| 采样参数 | 16 kHz / 16 bit / 单声道（固件固定） |
| 喇叭 | JST 座接入，阻抗待确认（2~4 Ω） |
| 尺寸 | 待实测 |
| 对接注意 | 背面丝印分组 `LRCLK/BCLK/SDA` = SPK、`DATA` = MIC，换批次可能对调，无声/无麦先核对这两脚；`CLK` 默认不接；喇叭只从 JST 座接入，不往功放输出端反接 |

## 八、电压检测模块（Voltage Sensor）

| 项目 | 参数 |
|---|---|
| 型号 | 页面标称 X9C103S 数字电位器模块，实物为 Voltage Sensor 分压模块（命名与实际功能不符，待确认） |
| 输入电压范围 | DC 0 ~ 25 V |
| 检测范围 | 0.02445 ~ 25 V |
| 分辨率 | 0.00489 V（按 10 位 AD、5V/1023 计） |
| 分压比 | 5:1（输入不得超过 AD 满量程 × 5） |
| 接口 | 蓝端子 `VCC` / `GND` 与被测电池正负极并联；`S` 接主控 ADC（GPIO8）；3 针 `+` 是分压电阻上端、与蓝端子 `VCC` 同电位，**不要接 3.3V/5V**，`−` 接 GND |
| 尺寸 | 待实测 |
| 固件状态 | **已接入**：GPIO8（ADC1_CH7）采样，5:1 还原 + 8 点滑动平均，`DAT_BAT` 上报真实电压（0.01 V）；`SENSOR_ENABLE` 默认 0，未接线时上报固定 6.80 V |
| 对接注意 | 取样点是电池原始电压（DC93512 原始电压输出），不是 5V/3.3V；8.4V 经 5:1 分压为 1.68V，低于 ADC 11 dB 档满量程；`VOLTAGE_CAL_GAIN` 默认 1.0，可用万用表实测后微调。**3 针 `+` 不可接 3.3V**，否则会与电池正极短接 |
