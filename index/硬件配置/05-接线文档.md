## 一、引脚对照总表

> **2026-11 引脚重排**：显示 / 音频 / 传感器集中在开发板**左侧排针**，两片 TB6612 的 8 条信号线集中在**右侧排针**。本文一律用 **GPIO 编号**表示引脚；实际排针位置以板卡丝印为准。

| 元件 | 型号 | 接到 GPIO | 排针侧 | 备注 |
|---|---|---|---|---|
| 主控板 | YD-ESP32-S3 V2.7（ESP32-S3-WROOM-1 N16R8） | 自身 | — | 3V3 输出供屏与两片 TB6612 逻辑电；5V 由 DC93512 OUT1 输入 |
| 彩屏 | 10PI-2D4TFT_V2.1（ST7789，240×320） | GPIO9 / GPIO10 / GPIO11 / GPIO12 / GPIO13 / GPIO14 | 左侧 | 依次 BLK / CS / SDA / SCLK / DC / RESET；6 条信号相邻，可一根 6P 排线一次插完，且都是 FSPI 原生 IO |
| 麦克风功放一体模块 | MAX98357A + INMP441（7Pin） | GPIO4 / GPIO5 / GPIO6 / GPIO7 | 左侧 | 依次 BCLK / LRCLK / SDA(功放) / DATA(麦)；`CLK`(MCLK) 悬空；VCC 走 OUT2 5V |
| TB6612 #1（左侧） | TB6612FNG | GPIO1 / GPIO2 / GPIO42 / GPIO41 | 右侧 | 依次 PWMA / AIN1 / AIN2 / STBY；A 通道驱左前+左后并联，B 通道接地 |
| TB6612 #2（右侧） | TB6612FNG | GPIO40 / GPIO39 / GPIO38 / GPIO47 | 右侧 | 依次 PWMA / AIN1 / AIN2 / STBY；与 #1 同构，VM、VCC、GND 共用 |
| DC93512 降压 | DC93512 V2.0 | 不占 GPIO | — | 三类输出：3.3V → 测速模块；5V → 主板 5V、音频 VCC；原始电压（直通电池）→ TB6612 VM、电压检测模块 |
| USB-UART 下载/日志 | 板载 CH340（Type-C UART 口） | GPIO43 / GPIO44 | 右侧 | UART0，115200 8N1；只接 TX / RX / GND |
| 电压检测模块 | Voltage Sensor（R1=3kΩ / R2=750Ω，5:1） | GPIO8（ADC1_CH7） | 左侧 | `S`→GPIO8；`+`/蓝端子 `VCC`→**电池原始电压正极**，`−`/蓝端子 `GND`→公共地；`+` 不要接 3.3V |
| 测速模块（单侧） | 单路脉冲测速模块（图中已有，每转脉冲数待实测） | GPIO15 | 左侧 | 只装**左后轮**；`OUT`→GPIO15 上升沿中断；右侧不装，`DAT_WHEEL` 右轮报 `0xFFFF` |

**为什么这样分侧**：

- **屏幕 6 线**取 GPIO9~GPIO14：6 条信号在左侧排针相邻，一根 6P 排线一次插完；并且 GPIO9/10/11/12 就是 SPI2（FSPI）的 HD / CS0 / D / CLK 原生 IO，40 MHz 走 IOMUX 不经过 GPIO 矩阵，是这块板上最快的 SPI 走法。旧方案 GPIO16/17/18/21/38/39 分散在两侧，且 GPIO39 与 I2S 的 GPIO39~42 存在历史占用冲突。
- **音频 4 线**取 GPIO4~GPIO7：紧邻屏幕线束上方的 4 条相邻信号，线束只往左侧走，不跨过板子中部。
- **电机 8 线**取右侧：GPIO1/2/42/41 与 GPIO40/39/38/47，PWM/方向/STBY 全部从右侧引出，线束直接进右侧电机区，不再横穿主板。
- **传感器 2 线**放左侧：电压检测**必须用 ADC1**（WiFi 工作时 ADC2 不可用），ADC1 只落在 GPIO1~GPIO10；其中 GPIO1/GPIO2 在右侧、已被电机 PWM 占用，左侧的 GPIO8 是唯一合适位置；且模拟取样与 8 条电机 PWM 分居两侧，减少干扰。测速是纯数字输入，跟着放在左侧。

### 1.1 找针位的办法

> **实际排针位置以板卡丝印为准**：正对板面、两个 Type-C 朝下，左右各一排针，按丝印上的 GPIO 编号对号入座即可，本文不逐脚列针位。
>
> 右侧排针中间夹着 Flash/PSRAM（GPIO26~37）、strapping（GPIO0 / 45）与板载 RGB（GPIO48），所以电机 #2 的 STBY 用 GPIO47，是 8 条电机线里唯一需要单独拉一根的地方；其余 7 条 GPIO1 / 2 / 42 / 41 / 40 / 39 / 38 在同一侧相邻。

### 1.2 逐信号选用理由（专用功能 / 分组 / 复用）

| 元件 | 信号 | GPIO | 为什么用这个脚 | 复用 |
|---|---|---|---|---|
| 彩屏 | BLK | 9 | FSPI 的 HD（IO_MUX 原生）；本屏不用 QSPI，HD 空着，用来当背光最划算，且落在屏幕 6 线连续段首位 | 是：FSPIHD |
| 彩屏 | CS | 10 | FSPICS0，硬件片选，IOMUX 直出 | 是：FSPICS0 |
| 彩屏 | SDA(MOSI) | 11 | FSPID，原生数据输出 | 是：FSPID |
| 彩屏 | SCLK | 12 | FSPICLK，40 MHz 走 IOMUX 不经 GPIO 矩阵 | 是：FSPICLK |
| 彩屏 | DC | 13 | FSPIQ（MISO）本屏只写不读，空出来当数据/命令线 | 是：FSPIQ |
| 彩屏 | RESET | 14 | FSPIWP 空出来当复位 | 是：FSPIWP |
| 音频 | BCLK | 4 | ESP32-S3 的 I2S 只能走 GPIO 矩阵、没有专用 IO_MUX，唯一要求是四根连续；GPIO4~7 正好一段，一根 4P 排线插完 | 否 |
| 音频 | LRCLK | 5 | 同上，紧邻 BCLK | 否 |
| 音频 | SDA（功放 TX） | 6 | 同上，数据线同段 | 否 |
| 音频 | DATA（麦 RX） | 7 | 同上，数据线同段 | 否 |
| 测速 | OUT | 15 | 普通 IO＋边沿中断，不是 strapping/USB/JTAG/Flash/PSRAM；紧贴音频段，线束同侧 | 是：U0RTS（不用硬件流控） |
| 电压检测 | S | 8 | **ADC1_CH7**：WiFi 下 ADC2 不可用，必须 ADC1；左侧排针上唯一空闲的 ADC1 通道（GPIO1/2 在右侧且已给电机） | 是：ADC1_CH7 |
| TB6612 #1 | PWMA | 1 | 右侧连续 7 组的起点，PWM 集中在一段便于整束引出 | 是：ADC1_CH0（只做数字输出，ADC 不启用） |
| TB6612 #1 | AIN1 | 2 | 紧邻 PWMA | 是：ADC1_CH1（同上） |
| TB6612 #1 | AIN2 | 42 | 同组连续 | 是：JTAG MTMS |
| TB6612 #1 | STBY | 41 | 同组连续 | 是：JTAG MTDI |
| TB6612 #2 | PWMA | 40 | 同组连续 | 是：JTAG MTDO |
| TB6612 #2 | AIN1 | 39 | 同组连续 | 是：JTAG MTCK |
| TB6612 #2 | AIN2 | 38 | 同组连续；v1.1 板载 RGB 也在此脚，仅外观影响 | 是：JTAG MTCK 组 / v1.1 RGB |
| TB6612 #2 | STBY | 47 | 被 Flash/strapping/RGB 隔开后的唯一空位；STBY 是上电拉高后的**静态电平**，线最长也不受干扰，所以把唯一的长线留给它 | 否 |

### 1.3 保留的空闲脚（给后续扩展 / PCB 余量）

| GPIO | 位置 | 保留理由 |
|---|---|---|
| 16 / 17 / 18 | 左侧，连续 3 个 | 一段连续排针，最方便加 3P/4P 排针或排母：超声、循迹、第二路测速、舵机都能直接用；不用时在 PCB 上留焊盘即可 |

### 2.4 TB6612 #1（左侧：左前 + 左后）

| 驱动端子 | GPIO / 去向 | 备注 |
|---|---|---|
| `PWMA` | 1 | A 通道 PWM，LEDC 通道 0，20 kHz / 10 bit |
| `AIN1` | 2 | A 通道方向位 1 |
| `AIN2` | 42 | A 通道方向位 2 |
| `STBY` | 41 | 高有效；低电平整板休眠（输出高阻） |
| `PWMB` / `BIN1` / `BIN2` | GND | B 通道不用，输入固定低；`BO1`/`BO2` 悬空不接 |
| `VM` | 电池正极 | 动力电，不经 DC93512 |
| `VCC` | 3.3V | 逻辑电，不可接 5V |
| `GND` | 公共地 | 逻辑地与电机地必须共地 |
| `AO1` | 左前 + 左后电机的同色线 | 两只电机同名端并接，负载并联 |
| `AO2` | 左前 + 左后电机的另一根 | 极性必须一致，不能一正一反 |

**并联接法**：#1 只承担左侧两轮，左前和左后**并到同一路输出**（`AO1` 接两只电机的同色线、`AO2` 接另两根），是负载并联，不是把两路输出并起来。B 通道完全不参与驱动，三个输入接地即可。差速转向靠左右两片驱动各给不同占空比，同侧两轮永远同速。

**方向与调速**（每片独立）：

| `AIN1` | `AIN2` | `PWMA` | 结果 |
|---|---|---|---|
| 1 | 0 | 占空比 | 正转，占空比决定转速 |
| 0 | 1 | 占空比 | 反转 |
| 0 | 0 | × | 停止（两输出低，滑行） |
| 1 | 1 | × | 停止（短路制动） |
| × | × | 0 | 停止 |

> `STBY=0` 时整片高阻，与上表无关。转向只看 `AIN1`/`AIN2`，与占空比大小无关。
>
> 并联接法：`AO1` 接同侧两只电机的同色线、`AO2` 接另外两根，是**负载并联**，同侧两轮永远同速；差速转向靠 #1 与 #2 各给不同占空比。

### 2.9 电压检测模块（Voltage Sensor，5:1）

> 当前固件 `SENSOR_ENABLE` 默认 **0**（只跑移动、传感器未接）：`begin()` 不碰 ADC / 中断，`DAT_BAT` 固定 6.80 V、`DAT_WHEEL` 左轮固定 0；接好线后改为 1 即启用真实采样。

| 模块丝印 | GPIO / 去向 | 代码宏 | 备注 |
|---|---|---|---|
| `S` | 8 | `PIN_VOLTAGE_ADC` | ADC1_CH7；`analogReadMilliVolts()` 已带校准 |
| `+`（3 针） | DC93512 **原始电压**输出 | — | 与蓝端子 `VCC` 是同一节点（分压电阻上端），**不要接 3.3V / 5V** |
| `−`（3 针） | 公共地 | — | 与蓝端子 `GND` 同一节点（分压电阻下端） |
| 蓝端子 `VCC` | DC93512 **原始电压**输出 | — | 取样点：电池原始电压，不是 5V 或 3.3V 输出 |
| 蓝端子 `GND` | 公共地 | — | 电池负极 |

**分压与换算**：模块是纯电阻分压，R1 = 3 kΩ、R2 = 750 Ω，
`V_S = V_bat × R2 / (R1 + R2) = V_bat / 5`，即分压比 **5:1**。

- `V_bat(V) = ADC_mV × 5 / 1000 × 校准系数`（`VOLTAGE_CAL_GAIN`，默认 1.0，待实测）
- `DAT_BAT` 上报值 = `round(ADC_mV × 5 / 10)`，单位 0.01 V
- 例：`S` 脚 1480 mV → 7400 mV → 上报 `740` → App 显示 7.40 V
- 满电 8.4 V 时分压后 1.68 V，低于 ADC 11 dB 档约 3.1 V 满量程，量程安全

> 模块只有两个分压电阻，3 针 `+` 就是分压电阻上端，与蓝端子 `VCC` 同电位。把 `+` 接 3.3V 会与电池正极短接，**绝对不能接**；取样只接电池原始电压。

### 2.10 单侧测速模块（只做左后轮）

| 模块丝印 | GPIO / 去向 | 代码宏 | 备注 |
|---|---|---|---|
| `VCC` | DC93512 3.3V 输出 | — | 必须 3.3V；`OUT` 电平随 VCC，5V 会超 GPIO 量程 |
| `GND` | 公共地 | — | — |
| `OUT`（或 `DO`） | 15 | `PIN_SPEED_PULSE` | 上升沿中断计数，内部上拉 |
| 码盘 | 左后轮 | — | **只装左后轮**；右后轮不装，右轮字段报 `0xFFFF` |

**换算**：`r/s = 脉冲数 / (每转脉冲数 × 窗口秒数)`，每转脉冲数取模块码盘实际槽数
（`SPEED_PULSES_PER_REV`，默认 **20，待实测**）；窗口 `SPEED_WINDOW_MS = 1000`。

- `DAT_WHEEL` 左轮值 = `脉冲数 × 100 × 1000 / (每转脉冲数 × 窗口 ms)`，单位 0.01 r/s
- 默认参数下：`左轮值 = 脉冲数 × 5`；`r/min = 左轮值 × 0.6 = 脉冲数 × 3`
- 例：1 s 内 100 个脉冲 → `500` → 5.00 r/s → 300 r/min
- 只测绝对值，**没有方向**；前进/后退都报正数
- `DAT_WHEEL` 右轮恒填 `0xFFFF`（-1，无效），App 应显示「右轮无数据」

### 3.1 复用引脚（必须知道）

| GPIO | 本方案用途 | 芯片原生 / 板载功能 | 取舍 |
|---|---|---|---|
| 9 / 11 / 12 | TFT BLK / SDA / SCLK | FSPI（SPI2）的 HD / D / CLK 原生 IO | 与 TFT 正好一一对应，直接走 IOMUX，无损失 |
| 10 | TFT CS | FSPICS0 | 正好当片选，无损失 |
| 13 / 14 | TFT DC / RESET | FSPIQ（MISO）/ FSPIWP | 本屏只写不读，MISO 与 WP 都不需要，改普通 IO |
| 1 / 2 | TB6612 #1 PWM / IN1 | ADC1_CH0 / ADC1_CH1 | 只做数字输出，ADC 不启用；电压检测改到 GPIO8 |
| 39 / 40 / 41 / 42 | TB6612 #2 AIN1 / PWM / #1 STBY / #1 AIN2 | JTAG：MTCK / MTDO / MTDI / MTMS | 只失去**外接 JTAG 探针**；ESP32-S3 内置 USB-JTAG 仍可用，串口日志（UART0，GPIO43/44）也保留 |
| 15 | 测速脉冲 | U0RTS（默认功能）/ ADC2_CH4 | 只做数字输入 + 内部上拉，UART0 硬件流控不用 |
| 16 / 17 / 18 | 空闲（预留） | U0CTS / U1TXD / U1RXD | 保留给后续超声 / 循迹，UART1 不用 |

> 板载 RGB 的引脚随板子版本不同：DevKitC-1 v1.0 为 GPIO48（本方案空着，不闪灯）；v1.1 为 GPIO38（本方案用作 #2 AIN2，转向时板载灯可能变色，仅外观影响，电机功能不受影响）。

**不可用作普通 IO**

| 类别 | GPIO | 原因 |
|---|---|---|
| Flash / PSRAM | 26 ~ 37 | 模组内部连接（N16R8 为 Octal PSRAM，35~37 亦被占用） |
| strapping | 0 / 3 / 45 / 46 | 上电电平决定启动模式 |
| USB | 19 / 20 | USB-JTAG / OTG |
| JTAG | 39 ~ 42 | 已让给电机信号；仅失去外接 JTAG 探针，内置 USB-JTAG 与 UART0 日志不受影响 |

**当前空闲**：GPIO16 / GPIO17 / GPIO18 / GPIO21。GPIO48 保留给板载 RGB。

**未分配 GPIO 的元件**：HC-SR04 超声波、TCRT5000 循迹模块均未接入固件，暂无引脚定义，见 01 第七节与价格总表。
